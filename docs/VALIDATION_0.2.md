# 0.2.0 歌名匯入版歷史驗證

此文件保留第一版完成時的結果。第二版已新增 SQLite，當前驗證見 VALIDATION.md。

使用者釐清：檔案只讀歌名；遊戲難度為 EASY／NORMAL／HARD，數值 LV 從畫面取得。已移除檔案難度、音符、時序及內容去重流程，JSON schema 升為 2；沒有資料庫需要遷移，也未覆寫舊報告。

## 自動測試

日期：2026-10-22（Asia/Tokyo）。Windows、Python 3.11.5，不需額外 Python 套件。

- `python -m unittest discover -s tests -v`（含 DANCE_SAMPLE_ROOT 真實樣本）：**20 項全通過**。
- `python -m compileall -q dance_results`：通過。
- 實際產出報告的 JavaScript 搜尋、組合篩選、空結果及群組篩選測試通過；HTML 列數與 JSON 歌曲資料夾數一致，ID 無重複，未引用外部資源。
- 刻意放入不合法音符、BPM、osu 模式／Version／難度參數，仍可正確取得歌名；不產生音符／難度相關輸出或警告。
- 驗證同資料夾多份檔案只產生一個歌曲項目；不同 Pack 同名歌曲分開；歌名衝突保留未知與候選。
- HTML 跳脫、報告禁止寫入 SONG、掃描範圍限制、備份排除、重新掃描一致性、未知編碼不猜字皆通過。

樣本資料夾全部原始檔（含音樂／圖片）測試前後 SHA-256 一致。

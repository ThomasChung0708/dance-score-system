# 歷史驗證：第二版（0.3.0／Phase 2）

日期：2026-10-22，使用者時區 Asia/Tokyo。Windows、Python 3.11.5，沒有安裝額外 Python 套件。SQLite 與報告均在專案目錄，SONG 保持唯讀。

## 自動測試

含真實歌曲樣本的 `python -m unittest discover -s tests -v`：**37 項全部通過**。

新增資料庫測試涵蓋：

- 相同路徑重掃不重複，歌曲與來源 ID 維持一致。
- 歌名更新保留身分與前次掃描快照；編碼失敗或來源衝突不蓋掉已保存歌名。
- 來源消失只標記、再次出現恢復原 ID；既有 Charts 與測試中的歷史外鍵關聯保留。
- 指定歌曲資料夾的掃描不影響其他 Pack；中止、讀取錯誤、略過連結及未遞迴的深層資料夾不誤標缺失。
- 根目錄、Pack、歌曲同名不跨來源合併；connect 不生成原始 Pack。
- 外鍵、難度三種限定與唯一性；引號等文字以 SQL 參數處理。
- 任一來源寫入失敗會回滾整次交易，不留下半次匯入。
- 拒絕將資料庫放入 SONG、拒絕覆寫不相容資料庫。
- 唯讀已存歌曲庫檢視不重新掃描、不增加掃描快照；保留缺失來源，禁止把快取冒充新掃描結果再匯入。

第一版的歌名／編碼／HTML 跳脫與唯讀樣本測試持續通過，原始樣本雜湊不變。`compileall` 通過。
